# Jak wnieść swój wkład (Contributing Guidelines)

Cześć! Cieszę się, że chcesz pomóc w rozwoju tego projektu. Ponieważ jest to małe, prywatne repozytorium udostępnione publicznie, poniżej znajdziesz kilka prostych zasad, które pomogą nam sprawnie współpracować.

Pamiętaj, że biorąc udział w tym projekcie, zobowiązujesz się do przestrzegania naszego [Kodeksu Postępowania (Code of Conduct)](CODE_OF_CONDUCT.md).

## 1. Zgłaszanie błędów i propozycji (Issues)

Zanim otworzysz nowe zgłoszenie, upewnij się, że podobny problem nie został już opisany w zakładce **Issues**.

Gdy tworzysz nowe zgłoszenie, postaraj się podać jak najwięcej szczegółów:
* **Opis problemu**: Co dokładnie poszło nie tak?
* **Kroki do odtworzenia**: Jak wywołać dany błąd krok po kroku?
* **Oczekiwane zachowanie**: Jak aplikacja/kod powinna zadziałać?
* **Środowisko**: Wersja systemu, język programowania, framework itp.

## 2. Proponowanie zmian w kodzie (Pull Requests)

Jeśli chcesz samodzielnie naprawić błąd lub dodać nową funkcjonalność:

1. **Zrób Fork** tego repozytorium na swoje konto GitHub.
2. **Utwórz nową gałąź (branch)** dla swoich zmian (np. `feature/nowa-funkcja` lub `fix/naprawa-bledu`).
3. **Wprowadź zmiany** w kodzie. Staraj się zachować spójny styl programowania z resztą projektu.
4. **Przetestuj zmiany** lokalnie, aby upewnić się, że niczego nie popsułeś/aś.
5. **Wyślij Pull Request (PR)** do gałęzi `main` (lub `master`) w tym repozytorium.

W opisie Pull Requestu krótko wyjaśnij, co zmienia Twoja poprawka i jaki problem rozwiązuje.

## 3. Styl opisów commitów

Dla zachowania porządku w historii projektu, staraj się pisać zwięzłe i jasne komunikaty commitów (najlepiej w języku polskim lub angielskim – zależnie od języka projektu), na przykład:
* `fix: naprawiono błąd z logowaniem`
* `feat: dodano nową funkcję eksportu do PDF`
* `docs: zaktualizowano plik README`

## 4. Kontakt i pytania

Jeśli masz pytania dotyczące działania projektu lub chcesz omówić większe zmiany przed napisaniem kodu, skontaktuj się ze mną bezpośrednio przez zakładkę **Issues**
